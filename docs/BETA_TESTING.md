# Internal Beta testing

Use Profile → Beta Center in Development or Preview builds. The checklist is stored separately from profile and diary data.

Recommended physical-device pass:

1. Install a clean Beta variant.
2. Time the First Minute flow from launch to the personalized home/day.
3. Test both first-entry confirmation and Skip.
4. Relaunch and verify onboarding does not repeat.
5. Verify Diary, Catalog, portion editing, QR, torch, Rhythm, Flow and Settings.
6. Test light/dark themes, Dynamic Type, Reduce Motion and VoiceOver labels.
7. Test background/foreground and offline relaunch.
8. Complete the persistent Beta checklist.
9. Export feedback and the technical report.

`Сбросить только onboarding для теста` clears only First Minute research/demo state. It does not clear the real profile, diary, products, recipes, Flow or SQLite.
