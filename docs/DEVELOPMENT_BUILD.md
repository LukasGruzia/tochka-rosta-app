# Development build

Development build is a separate `Точка Роста Dev` application with identifiers `ru.tochkarosta.app.dev` and scheme `tochkarosta-dev`. It keeps the Expo Go workflow intact and connects to Metro through the installed SDK 54-compatible `expo-dev-client`.

## Requirements

- Node.js and the installed project dependencies.
- Expo/EAS account authorization.
- Apple credentials and a registered device for a physical iPhone build, or Android credentials for Android.
- The project must be linked to an EAS project by the owner; do not invent `owner` or `projectId` values.

## Authorization and build

```powershell
cd "C:\Users\lukac\OneDrive\Desktop\tochka-rosta-app"
npx eas-cli login
npx eas-cli whoami
npx eas-cli build:configure
npx eas-cli build --platform ios --profile development
```

For Android, replace `ios` with `android`. For an iOS internal distribution build, use the device-registration link generated by the supported EAS workflow. Do not enter a made-up UDID.

## Run Metro for the dev client

```powershell
$env:APP_VARIANT = "development"
npx expo start --dev-client --clear
```

Open the installed `Точка Роста Dev` app and choose the local development server. The development build, unlike Preview, requires Metro for JavaScript changes.

## Recovery

- Verify the computer and phone are on the same network.
- Retry with `npx expo start --dev-client --clear --tunnel` when LAN discovery fails.
- Confirm `APP_VARIANT=development` before starting Metro.
- Rebuild after changing native dependencies, config plugins or permissions.
- Do not reset SQLite to repair a bundler connection.

Configuration follows the official [EAS build profiles](https://docs.expo.dev/build/eas-json/) and [app variants](https://docs.expo.dev/build-reference/variants/) guidance.
