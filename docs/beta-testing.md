# Beta 1: запуск и проверка

## Expo Go

Требования: Node.js 20.19+ и актуальный Expo Go, совместимый с Expo SDK 54.

```bash
npm install
npx expo start --go --clear --lan
```

Если iPhone и компьютер не видят друг друга в локальной сети:

```bash
npx expo start --go --clear --tunnel
```

На iPhone QR-код открывается системной Камерой. Metro должен оставаться запущенным.

## Тестовая сборка

В репозитории пока нет `eas.json`, поэтому самостоятельная EAS development/test build не настроена и не заявляется как созданная. Expo Go остаётся основным способом бета-проверки. Нативный Android-проект можно локально сгенерировать командой `npx expo run:android`; для локальной iOS-сборки нужен macOS с Xcode.

## Разрешения

- Камера — только для QR-кодов, штрихкодов и фотографии профиля/продукта по явному действию.
- Фото — только для выбора фотографии профиля или продукта.
- Микрофон не используется.
- Доступ к сети не нужен для SQLite, дневника, каталога, Ритма и demo mode; tunnel нужен лишь для соединения Expo Go с Metro.

## Обновление базы без потери данных

SQLite использует последовательные одноразовые миграции и `PRAGMA user_version`. Перед изменением схемы не удаляйте приложение и его данные. Миграции v1–v7 добавляют поля/индексы и не очищают пользовательские таблицы. Seed запускается только при изменении `seedDataVersion` и обновляет официальные данные, не пользовательские продукты.

Перед рискованной проверкой создайте JSON-копию: Профиль → Резервная копия данных. Импорт сначала проверяет формат, версию и состав, создаёт временную копию текущих данных, а затем выполняется одной транзакцией.

## Автоматические проверки

```bash
npm run typecheck
npm run lint
npm test
npx expo-doctor
npx expo export --platform ios
npx expo export --platform android
```

## Ограничение проверки

Автоматические проверки, Metro manifest и export подтверждают корректность JavaScript/TypeScript-контура. Splash, камера, системные разрешения, background/foreground, 20–30 минут работы и сохранность данных после принудительного закрытия должны быть подтверждены на физическом устройстве вручную.
